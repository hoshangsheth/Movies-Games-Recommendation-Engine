# API Reference

Base URL: `/api/v1`

Interactive OpenAPI docs are auto-generated by FastAPI and available at `/docs` (Swagger UI) and `/redoc`
once the backend is running.

---

## `GET /api/v1/health`

Health check. Confirms the recommender artifacts have loaded successfully.

**Response `200`**
```json
{
  "status": "ok",
  "movies_loaded": 4800,
  "games_loaded": 8200
}
```

---

## `POST /api/v1/movies/recommendations`

Returns movies similar to the given title.

**Request body**
```json
{
  "title": "Inception",
  "top_n": 10
}
```

| Field   | Type   | Required | Default | Notes                                  |
|---------|--------|----------|---------|-----------------------------------------|
| `title` | string | yes      | —       | A title, nickname, or known alias       |
| `top_n` | int    | no       | 10      | 1–50                                    |

**Response `200`**
```json
{
  "query": "Inception",
  "results": [
    {
      "Title": "Interstellar",
      "Top Cast": "Matthew McConaughey, Anne Hathaway",
      "Cast Picture": "https://...,https://...",
      "Description": "...",
      "Genre": "Adventure, Sci-Fi",
      "Language": "English",
      "Release Date": "2014-11-07",
      "Rating": 8.6,
      "Poster": "https://...",
      "Stream": "https://...",
      "Trailer": "https://www.youtube.com/watch?v=zSWdZVtXT7E"
    }
  ]
}
```

**Response `404`** — no fuzzy match could be found for the given title, or the input was empty:
```json
{ "detail": "Title 'xyzzy' is not in the data yet. It will be added in a future update." }
```

## `POST /api/v1/recommendations/{media_type}`

Unified endpoint that dispatches to either the movie or game engine.

**Path parameter:** `media_type` — `movie` or `game`

**Query parameters:** `title` (string, required), `top_n` (int, default 10)

```
POST /api/v1/recommendations/movie?title=Inception&top_n=5
POST /api/v1/recommendations/game?title=Elden+Ring&top_n=5
```

---

## `POST /api/v1/contact`

Submits the contact form. Appends a row to the configured Google Sheet (same spreadsheet and column
order as the original Streamlit app: timestamp, name, email, message).

**Request body**
```json
{
  "name": "Jane Doe",
  "email": "jane@example.com",
  "message": "Loved the recommendation engine!"
}
```

**Response `200`**
```json
{ "success": true, "detail": "Message sent. I'll get back to you soon." }
```

**Response `502`** — Google Sheets write failed (misconfigured credentials, sheet permissions, etc.):
```json
{ "detail": "Something went wrong. Please try again." }
```

---

## Error shape

Validation errors (missing/invalid fields) return FastAPI's standard `422` shape. All other handled
errors return:
```json
{ "detail": "<message>" }
```
Unhandled errors return a generic `500`:
```json
{ "error": "An unexpected error occurred." }
```
